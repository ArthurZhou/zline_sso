# 用户协议与隐私政策
**版本生效日期：2026年1月13日**

### 1. 服务定义
本系统作为身份认证中间层，仅负责将您的“进才工作台”身份通过 OIDC 标准协议安全地映射至关联业务应用，实现单点登录。

### 2. 数据处理
我们通过以下技术手段处理您的数据，确保信息在“流经”系统时的安全性：

#### A. 验证
* **加密传输**：当您提交登录信息时，数据在离开客户端前已通过AES-256-GCM算法加密。
* **重放攻击防护**：系统在处理请求时会强制校验时间戳。若请求偏离服务器当前时间超过预设阈值，该请求将被视为非法拦截攻击并直接作废。
* **二次加密验证**：解密后的凭据将立即使用“进才工作台”的RSA 公钥再次加密并转发验证。
* **存储声明**：**您的明文及加密密码本系统不会进行任何形式的存储。**

#### B. 身份关联
* **必要信息记录**：验证成功后，系统会在本地数据库中存储您的用户名、系统角色（Role）以及由进才工作台返回的**唯一标识码（xuid）**与**显示姓名（xuxm）**。
* **存储目的**：用于建立跨系统的账号映射关系以及便于您的管理员管理您的账号。

#### C. 访问控制
* **请求频率限制**：基于配置文件的阈值，对单位时间内的并发请求进行限制。这用于屏蔽暴力破解及拒绝服务攻击，相关 IP 信息仅在内存中用于计数，不进行长期留存。

### 3. 信息授权与分享
* **令牌发放**：系统基于 OIDC 标准生成包含您身份信息的 **JWT (JSON Web Token)**。该 Token 经过本系统 **RS256 算法** 数字签名，确保不可被篡改。
* **分享范围**：仅在您主动登录应用时，系统才会将您的用户名与角色信息发送至目标业务应用。

### 4. 法律与免责
* 鉴于本系统属于身份中转代理，若因“进才工作台”接口变更、服务宕机或账户冻结导致的登录受阻，与本平台无关。

### 5. 个人信息跨境传输告知
当您在校外环境（如家庭网络、移动网络）访问本服务时，您的数据将会通过 进才中学广电部提供的服务器 或 Cloudflare Inc. 进行中继。
在此期间，您的数据可能会被传输到中国大陆以外的国家或地区。

这些服务器仅用于中继数据，全部处理和存储均在校内服务器上进行。

您的数据在传输之前已经经过了充分的加密。
